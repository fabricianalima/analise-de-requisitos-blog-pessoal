**Requisitos do Sistema**

**Requisitos Funcionais (RF)**

- **[RF001] Autenticação de Usuário:** O sistema deve permitir o login de usuários cadastrados fornecendo e-mail e senha, retornando um token de autenticação JWT.
- **[RF002] Gerenciamento de Postagens:** O sistema deve permitir a criação, edição, listagem e exclusão de postagens no blog vinculadas a um tema.
- **[RF003] Filtro por Título:** O sistema deve permitir a busca de postagens pesquisando por palavras-chave contidas no título.
