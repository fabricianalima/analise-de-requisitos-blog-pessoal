**Requisitos Não Funcionais (RNF)**

- **[RNF001] Arquitetura Backend:** O serviço de API REST deve ser implementado em Java 17+ utilizando o framework Spring Boot.
- **[RNF002] Interface Frontend:** A interface de usuário deve ser construída em React com TypeScript e React Router para navegação SPA.
- **[RNF003] Segurança:** A transmissão de dados deve utilizar criptografia HTTPS e os endpoints da API devem ser protegidos por controle de acesso via Spring Security.
- **[RNF004] Tempo de Resposta:** As chamadas de leitura da API devem ter tempo de resposta inferior a 300 ms em condições normais de uso.
