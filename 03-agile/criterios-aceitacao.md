# Critérios de Aceitação

## Objetivo

Os critérios de aceitação definem as condições que devem ser atendidas
para que uma User Story seja considerada de acordo com o comportamento
esperado.

Neste projeto, os critérios foram definidos durante a elaboração e o
refinamento das User Stories.

## Características

Os critérios devem ser:

- Claros;
- Objetivos;
- Testáveis;
- Relacionados à User Story;
- Consistentes com os requisitos e regras de negócio.

## Exemplo

### US02 — Criar postagem

- [ ] O usuário deve estar autenticado.
- [ ] O título da postagem deve ser informado.
- [ ] O texto da postagem deve ser informado.
- [ ] Um tema deve ser associado à postagem.
- [ ] A postagem deve ser salva quando os dados forem válidos.

Os critérios completos estão registrados nas respectivas User Stories
do GitHub Projects.
