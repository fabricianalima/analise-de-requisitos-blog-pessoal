# Épicos e User Stories

## EP01 — Autenticação e Controle de Acesso

### US01 — Realizar login

**User Story:**  
Como usuário, quero realizar login utilizando meu e-mail e senha,
para acessar as funcionalidades do sistema.

**Requisito relacionado:** RF001 — Autenticação

---

## EP02 — Gerenciamento de Postagens

### US02 — Criar postagem

**User Story:**  
Como usuário autenticado, quero criar uma postagem,
para publicar conteúdo no blog.

**Requisito relacionado:** RF002 — Criar Postagem

### US03 — Listar postagens

**User Story:**  
Como usuário, quero visualizar as postagens cadastradas,
para consultar os conteúdos disponíveis no blog.

**Requisito relacionado:** RF004 — Listar Postagens

### US04 — Editar postagem

**User Story:**  
Como usuário autenticado, quero editar uma postagem,
para corrigir ou atualizar seu conteúdo.

**Requisito relacionado:** RF003 — Editar Postagem

### US05 — Excluir postagem

**User Story:**  
Como usuário autenticado, quero excluir uma postagem,
para remover um conteúdo que não deve mais estar disponível no blog.

**Requisito relacionado:** RF005 — Excluir Postagem

### US06 — Filtrar postagens por título

**User Story:**  
Como usuário, quero filtrar as postagens pelo título,
para localizar mais facilmente um conteúdo específico.

**Requisito relacionado:** RF007 — Filtrar por título

### US07 — Filtrar postagens por tema

**User Story:**  
Como usuário, quero filtrar as postagens por tema,
para visualizar conteúdos relacionados a um determinado assunto.

**Requisito relacionado:** RF008 — Filtrar por tema

---

**Requisito relacionado:** RF006 — Gerenciamento de Temas

**User Story:**

**Requisito relacionado:** RF006 — Gerenciamento de Temas

### US11 — Excluir tema

**User Story:**  
Como usuário autenticado, quero excluir um tema,

**Requisito relacionado:** RF006 — Gerenciamento de Temas
