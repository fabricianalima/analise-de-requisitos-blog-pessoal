# Product Backlog

O Product Backlog deste projeto é gerenciado utilizando o
GitHub Projects.

As User Stories foram organizadas em três épicos:

- EP01 — Autenticação e Controle de Acesso
- EP02 — Gerenciamento de Postagens
- EP03 — Gerenciamento de Temas

Cada User Story está registrada como uma GitHub Issue e vinculada
ao respectivo Epic no Project.

O backlog pode ser acompanhado diretamente pelo
[GitHub Projects](https://github.com/users/fabricianalima/projects/3).
