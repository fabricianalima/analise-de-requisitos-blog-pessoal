# Definition of Done

## Objetivo

A Definition of Done (DoD) estabelece os critérios necessários para
considerar uma User Story concluída no projeto.

## Critérios

Uma User Story será considerada concluída quando:

- [ ] A implementação da funcionalidade estiver concluída.
- [ ] Os critérios de aceitação forem atendidos.
- [ ] Os testes relacionados à funcionalidade forem realizados.
- [ ] O código estiver versionado no Git.
- [ ] O código tiver sido revisado.
- [ ] Não existirem erros que impeçam o funcionamento da funcionalidade.
- [ ] A documentação necessária estiver atualizada.

## Relação com os Critérios de Aceitação

Os Critérios de Aceitação verificam se a User Story atende ao
comportamento esperado.

A Definition of Done considera, além do atendimento aos critérios
de aceitação, aspectos relacionados à qualidade, testes, revisão,
versionamento e documentação.

Neste projeto, a DoD foi definida como uma referência para a
conclusão das User Stories.
